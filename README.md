# Coreon History Log — 0.2.0

Рабочая версия Figma Widget для UX-тестирования; публичная публикация ещё не выполнялась.

## Согласованные изменения

- UX-01. Быстрое добавление прямо на холсте через встроенный `Input`, без модального окна.
- UX-02. Единая хронологическая история в пределах экземпляра виджета: прежние режимы `product`/`ds` больше не переключаются. Старые данные остаются в `history-records-v1`, прежние v1-записи не перезаписываются. Category `Changed` по умолчанию, `Added`/`Fixed` по выбору, `Передано` — отдельное событие.
- UX-03. Отображение даты и времени до минут, исходное время создания сохраняется при правке.
- UX-04. Минимальный Markdown: `**жирный**`, `[название](https://...)`, `https://...` и маркированные/нумерованные списки. HTML и небезопасные схемы ссылок не интерпретируются.
- UX-05. Контекстная подсказка «Форматирование» на холсте при создании/редактировании и в окне истории.

Полная история доступна отдельно, поиск и фильтры сохранены, редактирование старых записей возможно. На холсте показываются лишь последние 3 / 5 / 10 / 15 записей, длинные многострочные записи ограничены 18 строками (полностью доступны в истории).

### Совместимость и ограничения

- Figma widget ID в `manifest.json` неизменен (`1703534862855031560`). Для обновления в Figma менять нужно лишь `dist/code.js` и `ui.html`.
- Объединение относится **только к одному экземпляру виджета**: истории разных копий виджета/других файлов Figma не объединяются.
- Markdown сохраняется как исходный текст; визуализация на холсте — Figma Text/Span; в HTML-окне — DOM без `innerHTML`.
- Inline Input в Figma фиксирует редактирование при выходе из поля (`onTextEditEnd`); для сохранения требуется отдельная кнопка.
- Хоткеи форматирования не добавлены: подсказка содержит синтаксис Markdown, как согласовано для первого этапа.
- Новые черновики внутри одного виджета синхронизируются через `useSyncedState`, как и другие настройки. При параллельном редактировании черновика двумя людьми возможны конфликты. Для утверждённого последовательного сценария это не критично.
- Это версия для дальнейших UX-итераций, **не публичный релиз**. Первичная проверка в Figma Desktop выполнена владельцем; полноценная проверка совместной работы и обновлений ещё впереди.

## Локальная проверка

```bash
npm install
npm run check
```

Локально пройдены 18/18 unit+smoke проверок; JS bundle и JS HTML-скрипт синтаксически проверены. Первичный ручной тест в Figma Desktop пройден владельцем; многопользовательский и реальный сложный файл не проверены.

См. [локальную установку](docs/LOCAL_INSTALL.md).
