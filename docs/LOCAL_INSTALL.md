# Локальная установка / обновление версии 0.2.0

COREON HISTORY LOG — 0.2.0

Функции:
1. Быстрое добавление записи прямо на холсте (без отдельного окна).
2. Единая история для всех записей, включая старые «Макеты» и «Дизайн-система».
3. Дата и время до минут рядом с автором.
4. Поддержка Markdown: **жирный**, [название](https://...), обычные https://..., - список, 1. список.
5. Подсказка «? Форматирование» в редакторе и в окне полной истории.
6. Категории Changed (по умолчанию), Added, Fixed и отдельная кнопка «Передано».
7. Лимит отображения 3 / 5 / 10 / 15 настраивается в свойствах виджета.

УСТАНОВКА В УЖЕ РАБОТАЮЩИЙ ВИДЖЕТ FIGMA DESKTOP:
1. ВАЖНО: протестируйте на копии файла Figma. Перед обновлением сохраните копию рабочей папки виджета.
2. Если в виджете оставлены тестовые записи от Benchmark, при желании очистите их тестовой сборкой ДО обновления. Иначе они сохранятся, что нормально.
3. В Figma: Widgets → Development → ваш Coreon History Log → Reveal in Finder.
4. Из этого архива замените только два файла в папке установленного виджета:
   dist/code.js
   ui.html
5. manifest.json НЕ ЗАМЕНЯТЬ. Не меняйте ID, не импортируйте новый виджет.
6. Вернитесь в Figma, обновите файл или перезапустите Figma Desktop при необходимости.
7. Проверьте кнопку + Добавить, сохранение, ссылку, списки, Вся история и старые записи.

Особенность редактора Figma Widgets:
Input сохраняет набранный текст, когда завершается редактирование: клик вне поля либо Cmd+Enter (Mac) / Ctrl+Enter (Windows). После этого нажмите «Сохранить». Если кнопка кажется неактивной, завершите редактирование поля и нажмите её повторно.

Версия фиксируется в публичном GitHub-репозитории, но пока не опубликована в Figma Community.
Тесты: 18/18 успешно (модель, логика виджета, HTML-история; без реального запуска внутри Figma).
